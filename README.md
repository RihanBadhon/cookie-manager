
# Cookie Manager
A lightweight and responsive Cookie Manager web interface built using HTML, CSS, and JavaScript. This project allows users to view, update, and select own browser cookies with a clean and intuitive UI.

## Features
✅ View all current cookies

➕ Add new cookies (name, value, expiry)

❌ Choose individual or all cookies

🖥️ Responsive design for all screen sizes

CSS3 

JavaScript
